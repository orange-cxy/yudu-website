# v1.1.0

本次发布完成了渔渡官网的完整搭建，基于 Vue 3 + Vite 构建，复刻配图 UI 并融合了渔渡 FX Gallery 的交互细节，实现了一个大气且富有细节的官网展示平台。同时，项目已配置 GitHub Pages 自动部署，支持在线预览。

## 新增功能

- **首页（/）**：实现品牌形象首屏，包含 Hero 区域（打字机文字+流光渐变标题）、核心优势卡片网格（3D 倾斜+悬停光晕）、最新动态/案例展示、底部联系/行动号召区域。
- **关于我们（/about）**：展示公司简介、使命、愿景、价值观，以及发展历程时间线（支持滚动进入视图动画）。
- **产品服务（/services）**：以卡片网格展示所有服务项目，支持点击展开详情或跳转至独立详情页（动态路由 `/services/:id`）。
- **案例展示（/cases）**：案例卡片列表（悬停放大/遮罩效果）与独立详情页（动态路由 `/cases/:id`），含面包屑导航。
- **联系我们（/contact）**：联系表单（姓名、邮箱、电话、留言，含实时验证与提交反馈）及公司联系信息（地址、电话、邮箱，支持一键拨号/发邮件）。
- **全局组件**：固定顶部导航栏（Logo + 菜单，移动端折叠汉堡菜单）、统一页脚（版权、快速链接、社交图标）、404 友好提示页面。
- **路由系统**：基于 vue-router 4，支持懒加载、导航守卫（自动更新页面标题）、404 捕获。

## 交互体验优化

- **粒子背景**：首页 Hero 区域加入动态粒子效果，增强视觉层次。
- **磁吸按钮**：CTA 按钮具备磁吸跟随光标效果，提升操作反馈。
- **导航下划线展开**：菜单项悬停时下划线平滑展开，强化导航交互。
- **滚动显现动画**：核心优势卡片、时间线、案例卡片等元素在滚动进入视口时渐显，提升浏览节奏。
- **产品架构图**：中心枢纽与四节点连线动画，直观展示产品体系。

## 技术架构与部署

- **项目基础架构**：Vue 3 Composition API + `<script setup>` 语法，Vite 构建配置，集成 vue-router 4，静态资源管理正常。
- **全局样式系统**：在 `src/style.css` 中定义 CSS 自定义属性（颜色、字体、间距等），支持响应式断点与基础重置样式。
- **自动部署**：新增 `release` 脚本，执行 `npm run build && gh-pages -d dist` 自动构建并推送到 `gh-pages` 分支，GitHub Pages 在线预览地址：https://orange-cxy.github.io/yudu-website/

## 其他

- 所有页面组件均采用 SFC 模式，样式结合全局 CSS 与 scoped 样式。
- 数据驱动渲染（静态 JSON 模拟），便于后期接入 CMS 或 API。
- 响应式布局覆盖桌面、平板、手机端。
